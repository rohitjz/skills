Make any page look made by hand, not AI-templated.

analog-ui is a skill for Claude Code and GitHub Copilot. Tell it what the page is for. It picks a real medium that does the same job (a blueprint for a roadmap, a receipt for pricing) and rebuilds it in code, with every number exact. Below: eight built examples. Click any to open the live page.

./install.sh analog-ui

The method

  1. Find the content's job. One thing the reader must remember, and who is reading.
  2. Pick a medium that does that job. A roadmap is a plan, so use a blueprint.
  3. List what's physically in it. Surface, marks, objects and the habits a native reader expects.
  4. Give every mark a job. A revision cloud means "changed". Cut anything that means nothing.
  5. Spend boldness once. One circle, one stamp, one highlighter. Keep the rest quiet.
  6. Render, look, fix. Check screenshots at every screen size, not just the code.

Tested

36page renders per run
3screen sizes, plus reduced motion
16tooling checks

On every push, each sample is checked for horizontal overflow, broken images, missing alt text, unlabelled graphics, tiny text, keyboard access to scrolling areas, endless animation and arithmetic that doesn't add up.
